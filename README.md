# SM Medi Lab Website

This is a modern, premium website for SM Medi Lab, built with Next.js 15+ and Tailwind CSS 4.

## Features

- **Home Page**: Premium design with hero section featuring medical diagnostic services.
- **Responsive**: Fully responsive design for mobile, tablet, and desktop.
- **Modern Tech**: Built using the latest web technologies for speed and performance.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Design System

- **Primary Blue**: `#002b5c`
- **Secondary Green**: `#28a745` / `#008a3e`
- **Typography**: Geist Sans (Next.js default)
